## 日常提效场景

### 场景一：随时随地远程办公

电脑在家开着，智能体在后台运行。不管你在哪，手机飞书里发消息就能指挥它干活。

**出门在外，突然收到工作任务**

有人在群里找你要一份文档，你不用赶回电脑前：

- 「帮我在我电脑上找一下上周的产品方案文档，发到项目群里」→ 智能体搜索本地文件，找到后直接发送
- 「顺便帮我查一下明天下午有什么会」→ 智能体查日程，手机端直接看结果

突然需要交一份材料，但手边没电脑：

- 「帮我建一个文档，标题是本周工作总结，先写个大纲」→ 智能体在云盘创建文档
- 「把今天会议的妙记链接找一下，贴到这个文档里」→ 智能体搜索群聊记录，找到链接写入文档

**核心价值**：读本地文件、搜云盘、建文档、发消息、查日程，手机飞书里直接搞定。智能体就是你的远程办公代理。

### 场景二：日程与提醒管理

工作事情多，容易忘。让智能体帮你管日程和提醒，到点自动执行。

- 「帮我看看这周有什么会」→ 列出本周所有日程，按天整理好
- 「周三下午那个会改到周四上午 10 点」→ 直接修改日程
- 「每天早上 9 点提醒我查看今天的待办」→ 创建 cron 循环任务，每天自动执行
- 「5 分钟后提醒我给张三打电话」→ 一次性延迟提醒，到点手机收到通知
- 「帮我建一个下周三下午 2 点的产品评审会」→ 直接创建日程事件

**核心价值**：日程查询、创建、修改、提醒，全部在飞书对话里完成。支持 cron 循环和一次性延迟任务。

### 场景三：数据处理与文档生成

从各种信息源收集数据、统计分析、整理成文档，这个过程最耗时。智能体帮你自动化完成。

**从表格到报告的全链路**

- 「帮我读一下桌面上那个销售数据表格，按区域汇总一下」→ 智能体读取本地表格，按区域统计
- 「跟 Q1 的数据对比一下增长了多少」→ 智能体继续读 Q1 表格，计算增长率
- 「把对比结果写成一份飞书文档，权限改成互联网所有人可阅读」→ 创建文档、改权限、返回链接

**从群聊到文档**

- 「帮我从项目群里搜一下上周关于 XX 功能的讨论，把关键结论整理出来」→ 搜索群聊历史，提取关键信息
- 「把这些结论写成一份文档，发到项目群」→ 创建文档、发送消息

**核心价值**：数据收集、统计分析、文档生成、权限管理，全链路自动化。省去大量手动整理的时间。

### 场景四：长对话方案讨论

讨论复杂方案需要连续聊 20 分钟以上。普通 AI 助手聊到后面就忘了前面说什么，智能体不会。

- 「帮我读一下这个需求文档，分析一下技术可行性」→ 读取文档，给出分析
- 「看一下我们之前有没有类似的方案」→ 搜索云盘和群聊历史，找到相关资料
- 聊了 25 分钟后：「回到刚才那个技术可行性的第二点」→ 智能体还记得第二点是什么
- 上下文快满了，自动压缩但保留决策和待办

**核心价值**：四级水位线管理上下文，工具结果全文搜索，被压缩的内容可按需恢复。30 分钟以上深度讨论也能保持连贯。

### 场景五：信息检索

信息散落在云盘、群聊、知识库各个地方，找起来费劲。智能体帮你跨平台搜索。

- 「帮我找一下之前那个关于用户增长的方案文档」→ 搜索云盘，找到文件并摘要
- 「这个文档当时在群里讨论过吗」→ 搜索群聊历史，找到相关讨论
- 「上周张三说过什么关于接口变更的」→ 搜索群聊历史，找到相关消息并整理

**核心价值**：云盘搜索、知识库搜索、群聊历史搜索、网络搜索，跨平台信息检索一次搞定。

### 场景六：一句话完成复杂工作流

一个任务涉及多个步骤，你只需要说一句话，智能体自动串联多个工具完成全部流程。

- 「帮我查一下明天的日程，如果有空的话建一个下午 3 点的评审会，然后给项目群发通知」→ 查日程 → 判断空闲 → 建会议 → 发消息
- 「帮我建一个文档，从这个需求文档里提取核心要点，权限改成公开可读，链接发到项目群」→ 读文档 → 提取要点 → 建文档 → 改权限 → 发消息

**核心价值**：一个指令，多步执行，不需要中间干预。每一步都有执行状态展示。

## 核心差异

### Aily 的优势（我们暂时不具备）

1. **多媒体能力**：AI 图片生成、视频理解、语音识别、播客生成
2. **PPT 和图表**：内置幻灯片生成和 Plotly 图表
3. **深度调研**：并行多源研究
4. **并行子任务**：map 工具支持并行执行

### 我们的优势（Aily 不具备）

1. **开放生态**：通过 MCP 和 Skills 可以连接任何外部工具。Aily 的能力边界由飞书平台定义，我们的能力边界由自己定义
2. **长对话不丢信息**：四级水位线 + 工具记忆全文搜索 + 飞书历史搜索
3. **自主可控**：每一个细节都可以根据反馈调优
4. **操作能力更强**：建文档、改权限、发消息、读表格，Aily 主要是「查」和「分析」，我们能「查」+「分析」+「操作」
5. **自主错误恢复**：工具失败时自动分析错误、查文档重试、权限不够自动发起授权

## 自主调优与持续进化

### 系统提示词持续迭代

智能体的「大脑」是系统提示词。我们把它从代码里抽离出来，做成独立的规则文件，可以随时修改和优化。

底层模型能力有限，有时候会笨拙、不听话、偏移、产生幻觉。这些不是模型能短期解决的问题，但我们可以通过不断迭代系统提示词来弥补：

- 某个场景下模型总是选错工具 → 加强工具路由规则
- 模型回复太啰嗦 → 加约束
- 模型对某个 API 参数总是猜错 → 加明确的参数格式和示例
- 模型遇到错误不会重试 → 加强错误恢复协议

迭代流程：发现问题 → 修改提示词 → 远程更新 → 软件自动检测 → 下次对话直接生效。不需要重新编译、不需要重新安装。

### 其他进化维度

- **工具定义扩展**：根据业务需求新增或修改工具
- **上下文管理策略调整**：根据使用模式优化水位线和压缩策略
- **技能系统扩展**：新增 lark-cli Skills，扩展智能体能力

## 未来规划：开放生态

### Skills 系统

智能体内置 lark-cli Skills 系统，支持用户自定义技能：

- 本机已安装的 Skills 自动发现和加载
- 用户可以编写自己的 Skill，扩展智能体能力
- 智能体根据用户意图自动选择最相关的 Skill

### MCP 协议扩展

通过 MCP 协议，可以连接任何外部工具：内部系统 API、外部 SaaS 服务、数据库查询、自定义脚本。

**与 Aily 的本质区别**：Aily 的工具扩展依赖飞书妙搭平台，是封闭生态。我们的智能体通过 MCP 和 Skills 实现开放生态，能力边界由自己定义。Aily 内置的图片生成、视频理解、PPT 制作、图表生成等能力，我们都可以通过接入对应的 MCP 服务器来实现。未来出现新的 AI 能力时，我们可以第一时间接入，不需要等飞书平台更新。

### 定时任务自动化

定时日报/周报自动生成、定期数据统计汇总、自动提醒通知、静默监控模式。

## 数据存储说明

- **飞书数据**：聊天记录、文档、表格等存储在飞书云端，通过飞书 API 访问
- **本地数据**：智能体会话历史、工具记忆、定时任务存储在本地 SQLite
- **混合模式**：核心业务数据在飞书云端，智能体运行数据在本地
