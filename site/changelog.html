v1.6.10 · Feishu Agent 稳定版

本次版本重点修复飞书 Agent 长流程中“只说下一步计划、没有真正调用工具”导致的中途假完成问题。

长流程稳定性

  • 当模型只输出“我将获取群聊消息记录”这类计划文本、但没有返回结构化工具调用时，Agent 会继续纠偏并要求真实调用工具。
  • 补充边界判断：缺少必要参数时仍会正常追问用户，已经形成总结时仍会正常结束，不会为了续跑而误入循环。
  • 新增 AI Build Demo Day 群聊消息类长流程回归测试，并覆盖追问、最终答复、普通聊天和最大工具轮次保护。

本地验证

  • 已通过 Feishu Agent 全包测试、核心代理工具测试和本地桌面包重建。
  • 本地安装包继续保留 Wails DevTools，便于右键打开 Inspect Element 排障。

v1.6.9 · Feishu Agent 稳定版

本次版本集中修复飞书 Agent 的工具感知、本机文件权限、定时任务和 Prompt Pack 下发链路，并新增 AI HOT / AI Radar 内置能力。

工具与权限

  • 强化模型工具感知与系统提示词路由，减少模型误判“没有工具”或“没有本机文件权限”的情况。
  • 本机文件操作会先检查授权路径，再按 read / write / delete 权限执行，避免在工具可用时直接拒绝。
  • 思考过程改为折叠面板展示，保留排障信息，同时减少可见重复回复。

定时任务

  • 调度器从固定轮询改为最近任务 timer，创建、删除、暂停、恢复后会立即唤醒重新计算执行时间。
  • 纯提醒任务到点后直接投递提醒正文，不再二次请求模型。
  • 定时任务消息升级为 CardKit 2.0，并具备 legacy card 与 Markdown 三级降级。

AI 热点能力

  • 内置 AI Radar 日报定时任务，使用 Agent 默认 workspace 和 AI HOT selected 信号，不需要本机项目路径、虚拟环境或脚本。
  • 新增即时 AI HOT 查询工具，用户问“今天 AI 圈有什么”“最近 AI 热点”等问题时可直接抓取真实标题、摘要、分类和链接。

内部 R2 与 Prompt Pack

  • 修复 R2 Prompt Pack 打包模块列表，新增的 schedule_templates 会随远端 Prompt Pack 一起发布。
  • App 端增加旧 Prompt Pack 缺模块时的本地嵌入兜底，避免远端规则落后导致新版本启动时报错。
  • 内部 OTA manifest 和 Prompt Pack 版本同步迭代，便于公司内部渠道分发。

v1.6.8 · Feishu Agent 稳定版

本次版本迭代完成了从 Bridge 到 Agent 架构更名与优化重构，重点打通了 Cloudflare Pages 非阻断部署及 R2 资源发布。

重命名与重构

  • 完成项目从 Bridge 到 Agent 的全面更名，并清理文档、源码及测试中的遗留 Bridge 字段与描述。

发布与部署优化

  • 升级 GitHub Actions 自动化构建与发布，大文件发布改走 AWS S3 API 规避 524 错误超时。
  • 优化 Cloudflare Pages 静态页面部署策略，支持非阻断式静默发布，打通官网自动发布及 R2 OTA 升级包检测闭环。

安全加固

  • 增强敏感路径文件操作的口诉授权追加逻辑。
  • 敏感文件删除（safe_file_delete）新增“参数 confirmed 校验 + 管理员口头指令确认”双保险二次验证，预防恶意注入越权误删。

v1.6.7 · Feishu Agent 稳定版

面向个人飞书智能体场景的一次完整增强，重点修复长内容、上下文、工具调用和发布下载链路。

核心飞书能力

  • 增强飞书云文档、云盘、电子表格、日历、消息、权限等核心工具调用。
  • 长文档和长表格支持分页读取、完整输出和多卡片续发，减少只读第一页或回复被截断的问题。
  • 权限处理区分“申请权限”和“公开分享权限”，避免把 apply-permission 当成公开设置。
  • 工具结果保留真实 URL、token、标题和分页状态，明确禁止编造链接。

上下文与记忆

  • 新增上下文预算、水位线、自动压缩和 `/context` 状态展示。
  • 工具结果按 preserve / summarize / stub / discard 分类压缩，降低长对话撑爆上下文的概率。
  • 引入 SQLite + FTS5 工具记忆，可通过工具记忆检索恢复被压缩的历史结果。
  • 支持飞书历史消息检索，用户说“上次/之前/继续”时能更可靠地恢复上下文。

工具生态

  • 接入 MCP session manager、工具清单缓存、动态 tool schema 和工具展开展示。
  • 支持 Agent Skills 导入、启用、查看和按需加载，脚本执行保留用户确认机制。
  • 补充通用 HTTP、Web、天气、定时任务、本地安全文件读写等基础工具能力。
  • 飞书 CLI prompt rules 模块化，并支持签名 Prompt Pack 远程更新。

桌面端与发布

  • 优化 Feishu Agent 高级设置、日志详情、区间复制、深色模式和 Windows/macOS 默认窗口体验。
  • 新增环境维护入口，可清理自动安装的飞书 CLI、官方 Skills 和授权信息。
  • 新增官网下载页、教程页、更新日志页，以及 R2 OTA manifest 发布链路。
  • 修复 R2 下载页 CORS，浏览器可直接读取最新版本 manifest。
