快速开始

  1. 安装并打开 Lingma Proxy。
  2. 确认 Base URL 指向企业上游模型服务。
  3. 在设置页执行“安装 CLI 与 Skills”。
  4. 初始化飞书应用并完成浏览器授权。
  5. 保存 Bridge 配置，启动 Feishu Bridge。
  6. 在飞书中与 Bot 对话，执行文档、云盘、表格、日历与消息任务。

常见问题

如果 CLI 或授权状态异常，可在 Feishu Bridge 高级设置中使用环境维护清理工具；不会清理 Node 环境，导入的 Skills 与 MCP 配置需要手动勾选才会清理。
